# Login Page UI

A simple, responsive login page built with plain HTML and CSS.

## Preview locally

Just open `index.html` in your browser, or run a tiny server:

```bash
npx serve .
```

## Files

- `index.html` — page markup (login form with email / password / remember me)
- `styles.css` — all styling (gradient background, card layout, focus states, responsive)

## Deploy

The site is static — deploy the folder to any static host (Netlify, Vercel, GitHub Pages).
